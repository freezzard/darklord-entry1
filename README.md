Entry for the make.fun bounty **The Tired Dark Lord: A 100-Word Villain Monologue**. `main.ts` assembles one original monologue of exactly 100 words (563 characters) — a fantasy villain who is secretly just very tired, felt in the sighing step, the ravens that left, and four hundred years of ledgers filed in triplicate — and writes it to `/output/entry.txt`. The output is deterministic: every run writes byte-identical output, and the program gate-checks the monologue (exactly 100 words, 1–600 characters, single paragraph, valid UTF-8, weariness never announced outright) before writing.

## Run it

```sh
node main.ts
```
